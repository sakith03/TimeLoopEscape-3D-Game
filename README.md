# Time Loop Escape - 3D Game🌀

## 🎮 Project Overview

**Time LoopcEscape** is a simple interactive 3D game developed for the *SE3032 – Graphics and Visualization* module. The game places the player inside a mysterious environment where time continuously resets, creating a looping challenge that must be broken through exploration and interaction.

The objective is to escape the loop by solving small environmental puzzles, interacting with objects, and learning from previous attempts before time runs out.

---

## 🧩 Core Features

* 🔁 Time loop mechanic with automatic scene reset
* 🏃 Player movement and interaction system
* 🔑 Object-based puzzle solving (keys, doors, etc.)
* 🧍 Custom 3D character with animations
* 🌍 Designed 3D environment with lighting and textures
